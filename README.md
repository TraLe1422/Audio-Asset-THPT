# Audio-Asset-THPT

Kho âm thanh và asset (hình, tệp dùng chung) của dự án Tiếng Anh THPT (Aiducation), phục vụ bản LMS.
Trang: https://trale1422.github.io/Audio-Asset-THPT/

Quy ước: mỗi bài một thư mục, ví dụ `writing-l10-u1/` (âm thanh: `W2.mp3`, ...). Asset dùng chung đặt trong `asset/`.
Chỉ đẩy lên sau khi người phụ trách duyệt.
